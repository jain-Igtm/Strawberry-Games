# Strawberry Forest Explorer — Godot rebuild

Fresh Godot 4.7 rebuild of the old Strawberry Forest concept. This project is intentionally isolated from the legacy Three.js version and from the other Strawberry Games Godot projects.

## What is implemented

- Deterministic infinite chunk streaming around the player
- Floating-origin rebasing for long-distance exploration without precision collapse
- Layered continental, hill, ridge, moisture, clearing and detail noise
- A continuous winding trail that deforms the underlying terrain rather than floating above it
- Wetland/lake pockets generated from lowland + moisture masks
- Procedural terrain material with slope-aware stone, moss, soil and wet-ground variation
- Instanced conifer forest with procedural bark, animated foliage and per-tree scale/lean/yaw variation
- Fern/groundcover fields, glacial rocks and fallen logs
- Rare deterministic ancient-stone landmarks
- Slowly changing natural light and atmospheric fog
- First-person walk, sprint, jump, camera sway, head bob, landing response and sprint FOV
- Android landscape multitouch: dynamic left movement stick, right-side look, jump and run controls
- Mobile-specific chunk radius/resolution limits and desktop-specific higher density
- GitHub Actions Android APK build pipeline

## Controls

Desktop: WASD or arrow keys move, mouse looks, Shift sprints, Space jumps, Escape releases the mouse. On Android, use the left side as a dynamic movement stick, drag the right side to look, and use the JUMP/RUN buttons.

## Rendering approach

The current pass deliberately does not depend on a downloaded art pack. Geometry, world placement and materials are generated by Godot code and shaders. That keeps the world seedable and the repository self-contained, while leaving a clean path for later photogrammetry trees, rocks, ground textures, wildlife, ambient audio and authored landmarks without rewriting the world streamer.

## Android build

The workflow `.github/workflows/build-godot-forest-explorer-apk.yml` installs Godot 4.7.1 and Android export tooling, validates the project headlessly, exports an ARM64 debug APK, and uploads it as `Strawberry-Forest-Explorer-debug-apk`.
