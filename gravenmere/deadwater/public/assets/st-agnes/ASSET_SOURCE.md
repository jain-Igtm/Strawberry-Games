# St. Agnes modular interior asset

Source: Modular Concrete Interior 3D by Keith / Fertile Soil Productions.

Source page: https://opengameart.org/content/modular-concrete-interior-3d

License: CC0 1.0 Universal.

The selected wall, doorway, corner, floor, ceiling, pillar and stair FBX modules were normalized, given consistent game-scale dimensions, combined into `st-agnes-kit.glb`, and supplied with 512px versions of the source material maps for the mobile build.
